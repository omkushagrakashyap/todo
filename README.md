# Todo App with Login

A modern Todo application built with **React**, **TypeScript**, and **Tailwind CSS** featuring user authentication, task management, and a responsive user interface.

## Features

* User authentication (Login)
* Create, edit, and delete todos
* Mark tasks as completed
* Responsive design
* Type-safe development with TypeScript

## Tech Stack

### Frontend

* HTML
* CSS
* JavaScript
* React
* TypeScript
* Tailwind CSS

## Prerequisites

Before starting, make sure you have:

* Node.js (v18 or later)
* npm or yarn
* A code editor (recommended: VS Code)

## Installation

Clone the repository:

```bash
git clone https://github.com/omkushagrakashyap/todo.git
```

Navigate to the project folder:

```bash
cd todo
```

Install dependencies:

```bash
npm install
```

## Running the Project

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```
